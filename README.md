# 机房维护系统 MRMS

面向机房（计算机教室/服务器机房）的集中维护系统：客户端零界面后台运行，
服务端网页汇总所有客户端（IP / 操作系统 / 用户名），支持远程屏幕查看与控制、
以管理员身份远程执行 cmd 命令（常用命令快捷选取自 sql.txt）、远程重启/关机。

> ⚠️ 本系统功能强大，仅限用于你拥有管理权限、且已获授权的设备。

## 一、目录结构

```
mrms/
├── server/                 服务端（Flask，部署在 10.100.4.111）
│   ├── server.py           服务端主程序
│   ├── config.json         配置（服务端 IP/端口、管理密码、接入令牌等）
│   ├── sql.txt             常用 cmd 命令（每行一条，启动时读取）
│   ├── requirements.txt    Python 依赖
│   └── templates/          网页（登录页 + 主面板）
├── client_cpp/             C++ 客户端（推荐，零依赖）
│   ├── MRMSClient.cpp      客户端源码（单文件）
│   ├── build_mingw.bat     一键编译脚本
│   └── client_config.json  客户端配置（可选，默认已内置服务端地址）
└── client_py/              Python 备用客户端（协议与 C++ 版完全一致）
    ├── client.py
    └── client_config.json
```

## 二、运行环境与依赖清单（你需要准备的全部）

### 服务端（Win10，1 台）
| 依赖 | 说明 |
|---|---|
| Python 3.8+ | 建议 3.10~3.12 |
| flask | `pip install -r requirements.txt` |
| waitress | 同上（可选但建议；装了自动启用，多线程更稳定） |
| 浏览器 | Edge / Chrome 访问管理页面 |

服务端**不需要任何 C++ 运行库**（纯 Python）。

### C++ 客户端（推荐，Win7 无SP / Win10 通用）
按本文档的编译方式（MinGW-w64 `-static` 或 MSVC `/MT`）编译出的
`MRMSClient.exe` **不需要安装任何 C++ 运行库和其它依赖**，拷贝即用。

- 若你改用 MSVC 动态链接（`/MD`），才需要安装：
  “Microsoft Visual C++ 2015-2022 运行库”（x86 客户端装 x86 版，x64 装 x64 版）；
  且 Windows 7 无 SP 还需 UCRT（KB2999226）。**因此强烈建议用静态编译，一劳永逸。**
- 编译工具：MinGW-w64（推荐 [winlibs](https://winlibs.com/) 或 MSYS2），或 VS2017+（含 C++ 桌面开发组件）。

### Python 备用客户端（仅当不用 C++ 版时）
| 系统 | 需要安装 |
|---|---|
| Win10 | Python 3.8~3.12 + `pip install pillow` |
| Win7 无SP | Python 3.8.x（官方支持 Win7 的最后版本）+ pillow≤9.5 |

无 pillow 时客户端仍可运行，但屏幕查看功能禁用（页面会提示）。
**Win7 无SP 的机器建议一律用 C++ 客户端**，最稳。

### 网络
- 服务端：防火墙放行 **TCP 3309 入站**。
- 客户端：只需要能访问 `http://10.100.4.111:3309`（出站），**无需开放任何入站端口**。

## 三、服务端部署

1. 把 `server/` 整个目录拷到服务器（如 `D:\mrms\server`）。
2. 安装依赖：`pip install -r requirements.txt`
3. 检查 `config.json`：

```json
{
  "server_ip": "10.100.4.111",     // 展示用服务端地址
  "port": 3309,                    // 监听端口
  "listen_host": "0.0.0.0",
  "admin_password": "mrcs123456",  // 网页登录密码，务必修改！
  "client_token": "MRCS-2026-DEFAULT-TOKEN",  // 客户端接入令牌，务必修改！
  "poll_interval": 5.0,            // 客户端轮询间隔（秒）
  "view_interval": 0.4,            // 屏幕观看时的轮询间隔（秒）
  "cmd_timeout": 120               // 远程命令超时（秒）
}
```

4. `sql.txt` 中维护常用命令，每行一条（`#` 开头的行忽略）。默认：

```
net user Administrator Ab123456
```

5. 启动：`python server.py`（已安装 waitress 时自动使用）。
   开机自启可用任务计划程序或 `nssm` 注册为服务，示例：
   `nssm install MRMS "D:\mrms\server\python.exe" "D:\mrms\server\server.py"`
6. 浏览器打开 `http://10.100.4.111:3309`，用 `admin_password` 登录。

## 四、C++ 客户端编译与部署

### 编译
在任一台装有 MinGW-w64 的机器上，进入 `client_cpp/` 目录双击
`build_mingw.bat` 即可产出 `MRMSClient.exe`。

- 生成的 exe 建议用 **x86 工具链**编译（可同时兼容 32/64 位系统）。
- 如需修改默认服务端地址/令牌，编辑 `client_config.json`（与 exe 同目录，
  缺省时使用内置默认值 `http://10.100.4.111:3309`）。

### 部署（每台客户端机做一次）
以**管理员身份**运行一次 `MRMSClient.exe`（或 `MRMSClient.exe /install`）即可，
它会自动：

1. 把自身复制到 `C:\ProgramData\MRMS\MRMSClient.exe`；
2. 创建开机自启动（登录触发的最高权限计划任务 `MRMS_Client`
   + 每小时守护任务 `MRMS_Client_Watch`；创建失败则回退注册表
   `HKLM\...\Run`，普通权限时写 `HKCU\...\Run`）；
3. 之后每次启动都会重新写入自启动项（被删除也会自愈）。

批量部署示例（域环境/远程）：

```bat
psexec \\PC-01 -c MRMSClient.exe /install
```

或放到共享目录后逐台以管理员运行。U 盘/共享目录直接双击运行亦可。

**杀毒软件**：静态编译的 MinGW 程序偶尔会被杀软误报，建议在机房统一
部署的杀软（360/火绒等）中将 `C:\ProgramData\MRMS\MRMSClient.exe` 加入
信任区/白名单。

### 卸载
管理员运行 `MRMSClient.exe /uninstall`：删除计划任务与 Run 项，
文件在下次重启时自动清除。

## 五、使用说明

- **客户端列表**：自动汇总显示 状态 / 主机名 / IP / 操作系统 / 用户名 /
  权限（管理员/普通）/ 分辨率 / 最后在线，3 秒自动刷新。
- **远程命令**：选中客户端 → 「远程命令」页签：
  - 下拉框选择 `sql.txt` 中的常用命令（自动填入），或直接输入任意命令；
  - 点击「执行」，输出实时显示（GBK 自动转 UTF-8，中文不乱码）；
  - 下方显示该机器最近执行过的命令与输出。
- **屏幕控制**：选中客户端 → 「屏幕控制」→「开始观看」：
  - 鼠标在画面上移动/单击/双击/右键 = 远程鼠标；
  - **按住左键拖动**：可拖拽窗口标题栏、框选文字、拖动滑块（v1.3 新增，
    鼠标可拖出画面边缘再松开）；
  - **键盘直通**：点击一下画面（出现蓝色边框表示已聚焦），随后直接敲
    物理键盘，按键会实时发送到远程（字母数字、Enter/Esc/Tab/方向键、
    F1~F12、Ctrl/Alt 组合键如 Ctrl+C、Alt+F4 等均支持）；点击页面其他
    地方即可解除聚焦；
  - 底部输入框可发送**整段文本（支持中文）**，按钮可发送单个功能键；
  - 「全屏画面」按钮进入全屏模式（按键栏保留），`Esc` 退出全屏。
- **电源**：远程重启 / 关机（有确认提示）。

### 远程文本输入的原理与去向

服务端网页发出的文本，最终被"打"在**客户端屏幕上当前获得焦点的窗口**
里——效果等同于有人坐在那台电脑前敲键盘（比如先远程单击桌面上的记事本，
再发送文本，字就出现在记事本里）。

技术链路：网页 → 服务端命令队列 → 客户端轮询取到 `KEY`/`SKEY` 指令 →
调用 Windows `SendInput` API 注入（普通字符走 `KEYEVENTF_UNICODE` 逐字符
注入，功能键/组合键走虚拟键码序列）。

需要提前做好的设置（仅 2 点）：

1. **客户端进程权限不能低于目标窗口**（Windows UIPI 安全机制）：客户端
   若以普通用户运行，则无法向"以管理员身份运行的程序"（如管理员 cmd）
   发送键盘鼠标输入。建议按第四章方式由管理员部署（计划任务以最高权限
   运行），即可操作任意窗口；
2. 客户端机器需处于**已登录、未锁屏**状态（锁屏/切换用户时输入无法到达
   桌面会话）。中文输入请用文本框整段发送（键盘直通不经过输入法，适合
   英文/命令/快捷键场景）。

## 六、权限说明（管理员身份执行命令的前提）

远程命令以**客户端进程自身的权限**执行：

- 客户端由管理员部署（本文档第四章方式）且机器以**管理员账户自动登录**
  （机房常见做法，尤其内置 Administrator 账户）→ 命令以管理员身份执行，
  `net user Administrator Ab123456` 这类命令可直接生效；列表中权限列显示
  「管理员」可核对。
- 若当前登录的是**普通用户**，命令以普通权限执行（列表权限列会显示
  「普通」），此时可先下发 `runas` 类命令或让该机器管理员登录后处理。
- 屏幕查看需要当前有用户登录（锁屏界面显示的是锁屏画面）。

## 七、已知限制

1. 屏幕帧率约 2~4 fps（HTTP 轮询式转发，局域网足够流畅，非远程游戏）。
2. 无法发送 `Ctrl+Alt+Del`（Windows 安全机制，任何远控软件都一样）；
   UAC 弹窗出现时屏幕可能变黑，此时在物理机上确认即可。
3. 客户端执行长时间命令（如 `ping -t`）期间画面会暂停，命令结束自动恢复
   （单线程轮询；超时由 `cmd_timeout` 控制，超时自动结束进程）。
4. 截图不包含鼠标指针位置（GDI 限制）。
5. Windows 7 无 SP 的机器优先用 C++ 客户端（Python 3.8 官方虽支持 Win7，
   但无 SP 环境未做充分测试）。

### 画面尺寸与 DPI（v1.2 修复说明）

客户端**必须使用 v1.2 及以后重新编译的 MRMSClient.exe**：程序启动时会
声明 DPI 感知（Per-Monitor-V2，Win7 回退 System）。此前的版本在
高分屏 + Windows 缩放（2560x1440@125%、4K@150% 等）下会被系统 GDI
虚拟化：画面右/下边缘缺失、鼠标点击坐标偏移。

- 验证方法：屏幕控制页观看时，按钮旁会显示「画面 2560x1440（应等于
  该机分辨率）」——显示的尺寸应与客户端列表中该机的分辨率完全一致；
  不一致说明客户端未更新到 v1.2。
- 学生机分辨率各异（1080p / 2K / 4K、单屏/双屏）均支持：截图覆盖整个
  虚拟桌面，坐标按比例归一化传输，与分辨率无关。
- Python 备用客户端同步修复（`SetProcessDPIAware` + `all_screens`）。

## 八、安全建议

- **立即修改** `config.json` 中的 `admin_password` 与 `client_token`
  （客户端 `client_config.json` 中的 token 同步修改）。
- 服务端仅限内网使用，不要映射到公网。
- 定期检查 `sql.txt` 与客户端机器的 `C:\ProgramData\MRMS\mrms_client.log`。
